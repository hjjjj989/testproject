## 👤 Автор 
**Миронов Андрей**
## 📖 Описание программы 
Консольное приложение для перевода валют. Позволяет перевести одну валюту в другую по текущему курсу, а также  сохраняет историю переводов  и Git. 

### Возможности: 
- ✅ Ввод валют (из и в)
- ✅ Перевести одну валюту в другую
- ✅ Сохранение данных перевода

## Примеры использования Выберите действие:
- Выбор первой валюты (из): RUS
- выбор второй валюты (в): USD
- Ввод суммы: 100
- Результат: 1,36
