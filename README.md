## 📖 Описание программы 
Консольное приложение для перевода валют. Позволяет перевести одну валюту в другую по текущему курсу, а также  сохраняет историю переводов  и JSON. 

### Возможности: 
- ✅ Ввод валют (из и в)
- ✅ Перевести одну валюту в другую
- ✅ Сохранение данных перевода

## Инструкция 

### Требования:
-Python 3.6 или Выше
-Установленная 6иблиотека Tkinter (обычно идёт в комплекте с Python)
### Запуск:
1. Откройте терминал или командную строку
2. Перейдите в директорию проекта:
3. "bash
cd bookTracker
"
4. Запустите приложение:
"bash
python main.py"

## Примеры использования Выберите действие:
- Выбор первой валюты (из): RUS
- выбор второй валюты (в): USD
- Ввод суммы: 100
- Результат: 1,36 

### Сохранение и загрузка:
- Нажмите **"Сохранить в JSON"** - данные сохранятся в файл save_history "

### Тестовые данные (примеры для проверки):

Попробуйте добавить данные для тестирования:
Из |RUB| В |USD| Сумма |100| Вывод |1,36|
## Валидация данных

Приложение проверяет:
-Все поля должны быть заполнены
-Сумма не должна быть отрицательной
